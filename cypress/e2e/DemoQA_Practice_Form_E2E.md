# Test Case: DemoQA Practice Form Submission Flow

## Objective
Validate the complete flow of accessing the DemoQA Practice Form, filling all fields, submitting the form, validating the confirmation popup, and closing it.

## Preconditions
- Internet connection available.
- DemoQA website accessible.
- A .txt file is available in the project repository and can be used for upload.

## Execution Steps

### 1. Access the Website
**Action:** Navigate to https://demoqa.com/

**Expected Result:**
- Home page is displayed successfully.

### 2. Open Forms Section
**Action:** Select the **Forms** option from the home page.

**Expected Result:**
- Forms section is displayed.

### 3. Open Practice Form
**Action:** Click on the **Practice Form** submenu.

**Expected Result:**
- Practice Form page is displayed.

### 4. Fill Out the Form
**Action:** Complete all form fields using random valid data.

**Expected Result:**
- All required fields are populated successfully.

### 5. Upload a TXT File
**Action:** Upload a .txt file from the project repository.

**Expected Result:**
- File is uploaded successfully.

### 6. Submit the Form
**Action:** Click the **Submit** button.

**Expected Result:**
- Form is submitted successfully.

### 7. Validate Confirmation Popup
**Action:** Verify the result after submission.

**Expected Result:**
- A confirmation popup is displayed.
- Submitted data is visible in the popup.

### 8. Close the Popup
**Action:** Close the confirmation popup.

**Expected Result:**
- Popup is closed successfully.
- User returns to the form page.

## Acceptance Criteria

The test will be considered successful when:

- The DemoQA website is accessed successfully.
- The Forms section is opened.
- The Practice Form page is displayed.
- All fields are completed with valid data.
- The .txt file is uploaded successfully.
- The form is submitted.
- The confirmation popup is displayed.
- The popup is closed successfully.

## Final Expected Result

The user is able to complete and submit the Practice Form, validate the confirmation popup, and close it without errors.
