# Test Case: DemoQA Web Tables CRUD Flow

## Objective
Validate the complete flow of creating, editing, and deleting a record in the Web Tables section.

## Preconditions
- Internet connection available.
- DemoQA website accessible.

## Execution Steps

### 1. Access the Website
**Action:** Navigate to https://demoqa.com/

**Expected Result:**
- Home page is displayed successfully.

### 2. Open Elements Section
**Action:** Select the **Elements** option from the home page.

**Expected Result:**
- Elements section is displayed.

### 3. Open Web Tables
**Action:** Click on the **Web Tables** submenu.

**Expected Result:**
- Web Tables page is displayed.

### 4. Create a New Record
**Action:** Create a new record using valid data.

**Expected Result:**
- Record is created successfully.
- New record is displayed in the table.

### 5. Edit the Created Record
**Action:** Update one or more fields of the created record.

**Expected Result:**
- Record is updated successfully.
- Changes are displayed in the table.

### 6. Delete the Created Record
**Action:** Delete the edited record.

**Expected Result:**
- Record is removed successfully.
- Record is no longer displayed in the table.

## Acceptance Criteria

The test will be considered successful when:

- The DemoQA website is accessed successfully.
- The Elements section is opened.
- The Web Tables page is displayed.
- A new record is created successfully.
- The created record is edited successfully.
- The edited record is deleted successfully.
- The deleted record is no longer visible in the table.

## Final Expected Result

The user is able to create, edit, and delete a record in the Web Tables section without errors.
