# Test Case: DemoQA Sortable List Flow

## Objective
Validate the complete flow of reordering sortable elements using drag and drop in ascending order.

## Preconditions
- Internet connection available.
- DemoQA website accessible.

## Execution Steps

### 1. Access the Website
**Action:** Navigate to https://demoqa.com/

**Expected Result:**
- Home page is displayed successfully.

### 2. Open Interactions Section
**Action:** Select the **Interactions** option from the home page.

**Expected Result:**
- Interactions section is displayed.

### 3. Open Sortable
**Action:** Click on the **Sortable** submenu.

**Expected Result:**
- Sortable page is displayed.

### 4. Reorder Elements
**Action:** Use drag and drop actions to arrange the elements in ascending order.

**Expected Result:**
- Elements are reordered successfully.
- The new order is reflected in the list.

### 5. Validate Ascending Order
**Action:** Verify the final arrangement of the elements.

**Expected Result:**
- All elements are displayed in ascending order.
- No drag and drop errors occur.

## Acceptance Criteria

The test will be considered successful when:

- The DemoQA website is accessed successfully.
- The Interactions section is opened.
- The Sortable page is displayed.
- Drag and drop actions are performed successfully.
- All elements are arranged in ascending order.
- The final order matches the expected ascending sequence.

## Final Expected Result

The user is able to reorder all sortable elements using drag and drop and place them in ascending order without errors.
